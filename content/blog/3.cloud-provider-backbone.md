## What Does a Cloud Provider Actually Do?

Cloud providers offer computing resources over the internet:

- **IaaS (Infrastructure as a Service)**: Raw virtual machines (e.g., ServerCore, AWS EC2)
- **PaaS (Platform as a Service)**: Managed environments (e.g., Heroku)
- **SaaS (Software as a Service)**: Ready-to-use apps (e.g., Gmail)
